# `swarmsim/agents/safety.py` — локальный слой безопасности (тактическое избегание, P5)

**Назначение.** Тактическое избегание столкновений (FR-5, MVP-3). Стратегическая
деконфликтуация — эшелоны по высоте (`agents.altitude_layers`, `altitude_step`); этот слой —
страховка на случай, когда эшелонов меньше, чем агентов, или они отключены.

## `@register_safety("none") class PassthroughSafety`
Команда без изменений. Ядро узнаёт этот класс и не собирает соседей — экономия времени.

## `@register_safety("orca") class OrcaSafety`
ORCA — J. van den Berg, S. Guy, M. Lin, D. Manocha, *Reciprocal n-Body Collision Avoidance*,
ISRR 2011; реализация — порт библиотеки RVO2 (`Agent::computeNewVelocity`, `linearProgram1–3`).

* **Соседи** — по бортовому обзору, а не по каналу связи: `SimLoop._sensed_neighbors` отдаёт
  агентов в радиусе `safety.sense_range` (60 м) **на том же эшелоне** (|Δh| < `vertical_separation`).
  Снимки соседей — до шага, у всех одинаковые (взаимность).
* **Полуплоскости скоростей** (`orca_lines`): для каждого соседа — область скоростей, не ведущих
  к столкновению на горизонте `orca_tau` (5 с); каждый берёт на себя половину поправки `u/2`.
  Радиус агента `orca_radius_factor · min_separation / 2` (2.2 · 5 / 2 = 5.5 м, сумма радиусов
  11 м > порога опасного сближения 10 м).
* **Границы поля** (`boundary_lines`): для каждой близкой стены `v·n ≥ −d / 1 с` — уклоняясь,
  нельзя вылететь за геозону (без этого агенты у точки старта на краю поля выталкивались наружу).
* **Выбор скорости**: ближайшая к желаемой, удовлетворяющая всем полуплоскостям и |v| ≤ v_max,
  — 2D линейное программирование `_lp2`; если допустимого нет — `_lp3` (минимум наибольшего
  нарушения), как в RVO2.
* **Прозрачность**: если поправка не нужна, возвращается исходная команда (`goto`) — траектории
  без конфликтов бит-в-бит совпадают с прогоном без фильтра (тест `test_orca_transparent_with_layers`).
* `n_conf` → `summary["N_conf"]`: число шагов, на которых фильтр изменил команду (docs/03, `N_conf`).

Параметры сценария (`safety:`): `filter: orca`, `sense_range`, `orca_tau`, `orca_radius_factor`.

Проверка — `tests/test_safety.py`: встречный и пересекающийся курсы держат дистанцию,
граница не пересекается, без эшелонов `N_col = 0` только с ORCA. Эффект в кампании — опыт A4
в `docs/reports/P5_comparison.md` (гипотеза H6).
