# `swarmsim/faults.py` — отказы ○ (владелец R3)

**Назначение.** Реализация `FaultManager`: отказы агентов **по расписанию** из сценария.
Нужна для тестов и демонстрации MVP-1.

## `@register_faults("scheduled") class ScheduledFaults(FaultManager)`
- `__init__` сортирует `faults.scheduled` по `(t, agent)` — детерминированный порядок.
- `inject_due(t, agents)` выдаёт все отказы с временем `≤ t` (с допуском `1e-9`), каждый
  один раз, с причиной `"injected"`.

Пример в сценарии:
```yaml
faults:
  kind: scheduled
  scheduled: [{t: 120, agent: 3}, {t: 240, agent: 7}]
```
Сам отказ обрабатывает ядро: `Agent.fail()` освобождает задачи и пишет событие
`agent_failed`.

## Что сделает R3
Случайные отказы с интенсивностью `λ` (экспоненциальное время до отказа, `docs/01`,
раздел 3.1, режим 2), используя переданный `rng`; «деградацию» (частичная потеря сенсора);
потерю GPS (SR-2).
