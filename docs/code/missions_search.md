# `swarmsim/missions/search.py` — миссия «поиск» ○

**Назначение.** Декомпозиция поисковой миссии в задачи (FR-2): территория режется на
квадратные секторы, в каждом строится маршрут «змейкой» (boustrophedon / lawnmower).
Одна задача — один сектор. Метод выбран по `docs/02`, антипаттерн 3: «Сначала — сетка +
змейка. Интеллект — в распределении, не в геометрии».
Литература: H. Choset, *Coverage of Known Spaces: The Boustrophedon Cellular
Decomposition*, Autonomous Robots, 2000; E. Galceran, M. Carreras, *A survey on coverage
path planning for robotics*, RAS, 2013.

**Импорты.** `math`, NumPy, `MissionPlugin`, `register_mission`, `Task`, `TaskSet`.

## `lawnmower(x0, y0, x1, y1, spacing) -> np.ndarray (K, 2)`
- Галсы идут вдоль оси x на высотах `y = y0 + spacing/2, y0 + 3·spacing/2, …`.
- Направление чередуется (туда — обратно), поэтому маршрут непрерывный.
- **Отступ `spacing/2` от левого и правого краёв сектора**, чтобы у аппарата с инерцией
  было место на разворот. Без отступа точки лежали на границе мира, и дуга разворота
  двойного интегратора выходила за неё (было 52 нарушения геозоны в `failures.yaml`).
- Если сектор уже одного шага — один галс посередине.

Шаг между галсами `track_spacing` (20 м) меньше ширины полосы обзора `W ≈ 58 м`: это
перекрытие ~2.9 раза. По модели случайного поиска это даёт `Pd ≈ 1 − e^(−2.9) ≈ 94 %`
за один облёт сектора.

## `@register_mission("lawnmower_grid") class LawnmowerGridMission`
### `decompose(world) -> TaskSet`
Для каждого сектора `sector_size × sector_size` (у краёв меньше): «змейка», точки внутри
бесполётных зон выбрасываются, сектор без двух точек пропускается. `area` = площадь
сектора. Задачи нумеруются подряд.

**Известное ограничение:** переходы между оставшимися точками идут по прямой и могут
пересекать бесполётную зону (`scenarios/nofly.yaml` даёт `N_geo > 0`). Обход — задача
планировщика или валидатора R2; для проверки есть `World.segment_is_free`.
