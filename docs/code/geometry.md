# `swarmsim/geometry.py` — 2D-геометрия ★

**Назначение.** Проверки для бесполётных зон и границ: точка внутри многоугольника,
пересечение отрезков, пересечение отрезка с многоугольником. Используется миром
(`in_nofly`, `segment_is_free`) и миссией (выбрасывание точек внутри зон).

**Импорты.** Только NumPy. Функции скалярные: многоугольников мало, а векторизация не
окупается.

## `point_in_polygon(p, poly) -> bool` — метод луча
Из точки `p` пускается горизонтальный луч вправо и считается, сколько рёбер он пересекает.
Нечётное число — точка внутри (правило чёт/нечет). Для каждого ребра `(x1, y1)–(x2, y2)`:
ребро пересекает прямую `y = p_y`, если `(y1 > y) != (y2 > y)`. Тогда абсцисса пересечения
`xc = x1 + (y − y1)(x2 − x1)/(y2 − y1)`, и если `x < xc`, пересечение лежит справа от
точки. Строгое и нестрогое неравенства корректно обрабатывают луч, проходящий через
вершину. Источник: E. Haines, *Point in Polygon Strategies*, Graphics Gems IV, 1994.

Работает для любых простых многоугольников, в том числе невыпуклых. `poly` — массив
`(K, 2)` без повторения первой вершины.

## `_orient(a, b, c) -> float`
Векторное произведение `(b − a) × (c − a)`: > 0 — поворот против часовой стрелки, < 0 —
по часовой, 0 — точки на одной прямой.

## `_on_segment(a, b, c) -> bool`
Лежит ли `c` (заведомо коллинеарная с `ab`) внутри прямоугольника отрезка `ab` (с допуском
`1e-12`).

## `segments_intersect(a, b, c, d) -> bool`
Классический тест ориентации (CLRS, глава 33.1):
- **общий случай**: `c` и `d` по разные стороны от `ab` **и** `a`, `b` по разные стороны
  от `cd` (`o1·o2 < 0 и o3·o4 < 0`);
- **вырожденные случаи**: одна из точек лежит на другом отрезке (ориентация 0 и
  `_on_segment`), включая касание концами.

## `segment_intersects_polygon(a, b, poly) -> bool`
`True`, если конец отрезка внутри многоугольника **или** отрезок пересекает хотя бы одно
ребро. Покрывает случаи «вошёл», «вышел» и «прошёл насквозь, не остановившись внутри».

## `polygon_bbox(poly) -> (xmin, ymin, xmax, ymax)`
Ограничивающий прямоугольник. Мир проверяет его первым: большинство отрезков далеко от
зон, и дорогая точная проверка не нужна.
