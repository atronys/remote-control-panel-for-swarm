# `swarmsim/sensing.py` — модель камеры и обнаружения ○ (владелец R3)

**Назначение.** Параметры сенсора → ширина полосы обнаружения `W` и вероятность
обнаружения за проход. Формулы — из `docs/02`, раздел 3.3; сама процедура обнаружения — в
`World.observe` ([world.md](world.md)).

**Импорты.** `math`, `SensorConfig`.

## Формулы
```
GSD       = H · pixel_pitch / focal_length                 разрешение на местности, м/пиксель
footprint = 2 · H · tan(FOV/2)                             ширина кадра на земле, м
W         = footprint · min(1, GSD_target / GSD),  если GSD ≤ GSD_max,  иначе 0
Pd        = 1 − exp(−W · L / A_cell)                       Купман, «случайный поиск»
```
Смысл `W`: пока разрешение не хуже нужного (`GSD ≤ GSD_target`), цель различима во всём
кадре. Когда разрешение хуже, эффективная полоса сужается пропорционально. Когда хуже
предельного (`GSD_max`), цель не видна вовсе. Функция `f(x) = min(1, x)` — простейший
выбор для `W = W_max · f(GSD_target/GSD)` из `docs/02`.

Параметры по умолчанию: FOV 60°, пиксель 3 мкм, фокус 8 мм, целевой GSD 2 см, предельный
5 см. На 50 м: GSD = 1.9 см, W = 57.7 м. На 100 м: GSD = 3.75 см, W ≈ 61.6 м. На 200 м:
GSD = 7.5 см > 5 см, W = 0.

Источники: формула GSD — стандартная фотограмметрия; `Pd` — B. O. Koopman, *Search and
Screening*, 1946 (см. [00_libraries_and_sources.md](00_libraries_and_sources.md)).

## `class SensorModel`
| Метод | Возвращает |
|---|---|
| `gsd(alt)` | GSD на высоте |
| `footprint(alt)` | ширина кадра |
| `swath_width(alt)` | `W`, с кэшем по высоте (у каждого агента своя постоянная высота) |
| `pd_pass(length, width, cell_area)` (статический) | `1 − exp(−W·L/A)` |

## Что может сделать R3
Контраст цели, погода и освещённость (множитель к `W`), ложные тревоги, модель
«определённого радиуса» (definite range law) как альтернатива случайному поиску.
