# `swarmsim/metrics.py` — метрики ○ (владелец R4)

**Назначение.** Базовый набор метрик из `docs/03`, раздел 4, который ядро умеет считать
само. R4 расширяет его (T_latency, T_realloc, T_recovery, B, CPU и т. д.).

**Импорты.** `typing`, `Mode`, `TaskSet`, `TaskStatus`.

## Константы
- `DETECT_LEVELS = (0.5, 0.9)` — пороги для `T_detect_50` и `T_detect_90`.
- `WALLCLOCK_FIELDS = ("wall_time_s", "realtime_factor")` — поля, зависящие от скорости
  компьютера. Исключаются из проверки детерминизма.

## `class MetricsRecorder`
### `record(t, world, agents, tasks)` — вызывается каждый шаг
- **Каждый шаг** проверяет пороги обнаружения: `T_detect_X` — первый момент, когда
  Pd-взвешенная доля ≥ X (определение из `docs/03`); `T_detect_X_realized` — то же по
  фактически найденным целям.
- **Раз в `record_every` секунд** добавляет строку во временные ряды и, если включено,
  по строке траектории на каждого агента.

### `finalize(t_final, world, agents, tasks, extra) -> dict` — итог прогона

| Поле | Смысл |
|---|---|
| `t_final` | модельное время окончания |
| `T_detect_50/90`, `..._realized` | время обнаружения 50 / 90 % целей (`None`, если не достигнуто) |
| `detected_frac`, `expected_detect_frac` | фактическая и Pd-взвешенная доля найденных |
| `targets` | число активных целей |
| `tasks_total`, `tasks_done`, `tasks_orphaned` | задачи: всего, выполнено, остались ничьими |
| `CR` | доля выполненных задач |
| `makespan` | время выполнения последней задачи |
| `E_total_Wh`, `distance_km` | суммарные энергия и путь |
| `agents_failed`, `agents_landed` | итоговые состояния агентов |
| `N_col`, `N_nm`, `N_geo`, `N_dup` | столкновения, опасные сближения, нарушения геозон, дубли |
| `valid` | `N_col = 0 и N_dup = 0 и N_geo = 0` — прогон корректен |

Жёсткие ограничения — **условия корректности, а не метрики** (`docs/03`): невалидный
прогон не входит в статистику стенда, но считается отдельно.
