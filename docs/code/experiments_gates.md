# `experiments/gates.py`, `campaign.py`, `stats.py` — контрольные точки P2–P5

```
python -m experiments.gates p2 --jobs 11      # распределение: жадный vs лучшее известное
python -m experiments.gates p3 --jobs 11      # отказы 20 % + новая цель
python -m experiments.gates p4 --jobs 11      # разрыв со станцией 30 % + деградация канала
python -m experiments.gates p5 --jobs 11      # кампания docs/03, графики 1–6, статистика
python -m experiments.gates p5 --report-only  # пересобрать отчёт по готовым CSV
```
`--quick` — по 1–2 зерна для отладки конвейера (отчёт тогда не доказательство).
Каждая команда пишет `docs/reports/<фаза>.md`, сырые CSV и графики в `docs/reports/figures/`.
Числа в отчётах — только из этих прогонов; критерии и правила вердиктов записаны в коде до прогона.

## `stats.py` (docs/03 §7)
* `paired(x, y)` — по зёрнам: средняя разность с бутстреп-CI95 (1000 ресемплов), парный
  Уилкоксон, ранговая бисериальная корреляция `r_rb`, относительная разница. Если все пары дают
  одну и ту же разность — `det = True`: мир не зависит от зерна, эффективный объём выборки 1,
  p-value не считается (иначе 20 одинаковых прогонов дали бы «p < 10⁻⁵» — псевдоповторность).
* `describe(xs)` — mean, CI95, median, IQR.

## `campaign.py` (P5)
Опыты: E1 (N), E1h (N на мире с горячими зонами — меняется от зерна), E1b (N при M = 100),
E2 (λ отказов), E3 (качество канала q, в номинале и с нарушениями), E3L (кривая потерь),
E4 (нестационарность D), E5 (неоднородность κ), абляции A1–A4. Все методы одного опыта — на
одних зёрнах. Невалидные прогоны (N_col, N_dup, геозона) исключаются из статистики качества и
показываются отдельно. Графики 1–6 docs/03 §6 → `figures/P5_*.png`.
