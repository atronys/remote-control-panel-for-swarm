# `apps/viz.py` — картинка траекторий ★

**Назначение.** Быстрая отладочная картинка прогона. Это не графический интерфейс:
полноценная визуализация по `docs/02` делается позже и «производна от метрик».

**Импорты.** `csv`, `json`, `pathlib`; matplotlib (бэкенд `Agg` — рисование в файл без
окна) подгружается внутри функции, чтобы ядро не зависело от matplotlib.

## `plot_run(run_dir) -> Path`
1. Из `run_manifest.json` берёт размер мира и бесполётные зоны.
2. Из `trajectories.csv` собирает трек каждого агента.
3. Рисует зоны (красная заливка) и треки (свой цвет на агента), равный масштаб осей,
   заголовок «сценарий · распределитель · зерно».
4. Сохраняет `trajectories.png` (130 dpi) в папку прогона.

Вызывается через `swarmcore run ... --plot`.
