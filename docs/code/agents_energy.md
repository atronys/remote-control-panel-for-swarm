# `swarmsim/agents/energy.py` — энергопотребление мультиротора ★

**Назначение.** Сколько мощности (Вт) тратит мультиротор при горизонтальном полёте со
скоростью `v`, и производные величины: характерные скорости и энергия на перелёт.
Используется агентом каждый шаг (расход батареи) и для решения «пора домой».

**Источник модели.** Y. Zeng, J. Xu, R. Zhang, *"Energy Minimization for Wireless
Communication With Rotary-Wing UAV"*, IEEE Transactions on Wireless Communications, 2019.
Формула приведена в `docs/02`, раздел 3.2; параметры по умолчанию (`EnergyConfig` в
`scenario.py`) — из таблицы параметров статьи.

**Импорты.** NumPy (векторные вычисления и поиск минимума по сетке), `EnergyConfig`.

## Формула

```
P(v) = P0·(1 + 3v²/U_tip²)                                   ← профильная мощность лопастей
     + Pi·√( √(1 + v⁴/(4·v0⁴)) − v²/(2·v0²) )                ← индукционная (создание тяги)
     + ½·d0·ρ·s·A·v³                                          ← паразитная (сопротивление корпуса)
```

| Параметр | Значение | Смысл |
|---|---|---|
| `P0` | 79.86 Вт | профильная мощность в висении |
| `Pi` | 88.63 Вт | индукционная мощность в висении |
| `U_tip` | 120 м/с | скорость кончика лопасти |
| `v0` | 4.03 м/с | средняя индуцированная скорость в висении |
| `d0` | 0.6 | коэффициент сопротивления фюзеляжа |
| `ρ` | 1.225 кг/м³ | плотность воздуха |
| `s` | 0.05 | коэффициент заполнения ротора |
| `A` | 0.503 м² | площадь диска ротора |
| `E_takeoff` | 2000 Дж | фиксированная стоимость взлёта (наша оценка: ≈ 12 с висения) |
| `E_land` | 1000 Дж | фиксированная стоимость посадки (наша оценка) |

`E_takeoff` и `E_land` — не из статьи: это слагаемые `N_takeoff·E_takeoff + N_land·E_land`
из `docs/02`, значения подобраны как порядок величины. Их стоит уточнить по реальному
аппарату.

## Что получается (посчитано нашим кодом)

| Скорость | Мощность | Комментарий |
|---|---|---|
| 0 м/с (висение) | 168.5 Вт | `P0 + Pi` |
| 10.2 м/с | 126.0 Вт | **минимум мощности → максимальная продолжительность полёта** |
| 12 м/с (крейсерская по умолчанию) | 127.8 Вт | почти минимум |
| 18.3 м/с | 161.6 Вт (8.8 Дж/м против 10.7 Дж/м на 12 м/с) | **минимум энергии на метр → максимальная дальность** |
| 30 м/с | 356.3 Вт | паразитная мощность растёт как `v³` |

Кривая **U-образная**. Висение — не самый экономный режим: на скорости часть тяги даёт
набегающий поток, и индукционная мощность падает.

### ⚠ Расхождение с `docs/02`
В `docs/02`, раздел 3.2, написано: минимум мощности «≈ 1–3 м/с», максимум дальности «≈ 10–15 м/с».
По **той же формуле с параметрами той же статьи** получается 10.2 и 18.3 м/с (проверено
тестом `test_power_curve_shape`). Формула в документе верна, неверны поясняющие числа.
Вывод документа о том, что «дальность и продолжительность оптимальны на разных скоростях,
и это делает распределение содержательным», **остаётся верным**. Стоит поправить текст
`docs/02` решением команды.

## `class RotaryWingEnergy`

### `__init__(cfg: EnergyConfig)`
Сохраняет параметры и заранее считает `P(v)` на сетке `0…35 м/с` с шагом 0.01 (3501 точка)
для поиска характерных скоростей.

### `power(v) -> float | np.ndarray`
Формула выше. Принимает и число, и массив скоростей (векторизовано через NumPy), и
возвращает того же вида.

### `hover_power -> float` (свойство)
`P0 + Pi` — мощность в висении.

### `energy_per_meter(v)`
`P(v)/v`, Дж/м. В висении — бесконечность (деление на ноль подавлено `np.errstate`).

### `v_min_power() -> float`
`argmin P(v)` по сетке — скорость максимальной продолжительности.

### `v_max_range() -> float`
`argmin P(v)/v` по сетке (без `v = 0`) — скорость максимальной дальности.

### `energy_for_distance(distance, v) -> float`
Энергия на перелёт с постоянной скоростью: `P(v) · distance / v`. Используется агентом
для оценки «хватит ли энергии долететь домой».

## Как энергия используется в симуляции
- Каждый шаг агент тратит `P(|v|)·dt` (в `Agent.step`).
- Взлёт и посадка — фиксированные `E_takeoff`, `E_land`.
- Ветра нет (`docs/02`: «отсутствие ветра … на MVP-этапах»), поэтому воздушная скорость
  равна путевой. При добавлении ветра в `power()` нужно передавать `|v − wind|`.
- Затраты на ускорение отдельно не учитываются: модель Zeng — для установившегося полёта.

## Проверка NFR-11
Батарея 55 Вт·ч, резерв 20 %, 12 м/с: `55·3600·0.8 / 127.8 ≈ 1240 с ≈ 20.7 мин`. Требование
«≥ 15 мин» выполнено (`test_endurance_matches_nfr11`).
